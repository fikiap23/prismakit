# PrismaKit Cursor skills (pointer)

Skills live in [`skills/`](../../skills/) at the repository root (the well-known path for `npx skills add`).

## Install

```bash
# In any PrismaKit app (preferred — same UX as large frameworks)
npx prismakit skills
npx prismakit skills --global
npx prismakit skills --with-rules

# From this git clone, without the CLI
bash templates/cursor-skills/scripts/install.sh
bash templates/cursor-skills/scripts/install.sh --project
```

Always-on editor rule (complement, not a replacement): [`../cursor-rules/data-access.mdc`](../cursor-rules/data-access.mdc).
